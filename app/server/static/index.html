✍ Заполнить форму

Должность, город, опыт, навыки и ожидания по зарплате — за минуту.

Навыки
Навык выбирается только из словаря (по данным hh): начните вводить и кликните по совпадению. Своё значение внести нельзя.
Опыт работы
Каждому месту работы — свой опыт: задачи, проекты, результаты. Влияет на подбор вакансий и текст писем.

Разрыв в навыках

Какие навыки рынка есть в вакансиях вашего стека, но отсутствуют в резюме. Доля — % вакансий стека, где навык встречается.

Черновики писем

Черновики создаёт агент в чате (попросите: «Напиши сопроводительное письмо на вакансию …») и сохраняет только локально. Здесь их можно открыть, поправить текст руками, перегенерировать и скопировать — отправляете работодателю сами, автоматической отправки нет.

Учёт откликов

Это ваш личный трекер: таблица «куда откликнулся и на какой стадии». Записи создаются вручную (поиск вакансии ниже) или через чат («запиши отклик по вакансии …»). Статусы меняете только вы: агент не отправляет отклики и не читает переписку (API откликов hh для приложения недоступен). Ничего никуда не уходит — данные только локальные.
