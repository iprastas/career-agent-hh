# AGENTS.md

Если в репозитории есть `.nexus-map/INDEX.md`, сначала прочитай его, затем перед выполнением задачи прочитай все файлы, перечисленные в его операционном блоке (arch/systems.md, arch/dependencies.md, arch/test_coverage.md, hotspots/git_forensics.md, concepts/domains.md).

Если `.nexus-map/` нет, а задача затрагивает межмодульные изменения или интерфейсы, предложи пользователю запустить nexus-mapper; если нужно начать немедленно — хотя бы выполни `query_graph.py --summary` для структурного понимания.

Когда задача меняет структурное понимание проекта (границы систем, точки входа, зависимости), перед сдачей оцени, нужно ли обновить `.nexus-map/`.
